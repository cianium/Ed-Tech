# Scope freeze — approved product intent
- **M0 only in this package:** noninteractive Next.js foundation, design tokens, env validation, fail-closed flags, pure architectural unit tests, quality scripts, docs and CI definition.
- **P0 for later milestones:** B2C English/German path from onboarding to progress; B2B academy path from invitation to teacher review; identity with multiple memberships; real API resource checks and RLS; restricted minor onboarding and verified guardian grants; curated resource library; constrained text-only AI; short Word Forge; accessible mobile operations and privacy.
- **Excluded:** payments, SMS, blogs/advanced CMS, native clients, high-stakes AI grading, public minor leaderboards, unlimited open chat, voice/video tutor, marketplace and creator economy.
- **Commercial stage:** free Iran-first pilot, ~100 people and 1–3 academies *targets*, not demonstrated throughput.
- **Release:** cannot ship until provider legality, minor safeguards, RLS negative tests, AI evaluation, content approvals and operational evidence are complete. No feature can be added to P0 without change review.

Authority: 01 (governing), 03–12 baseline, Blueprint (later founder decisions); preserve unresolved conflicts in ADRs.
