# ADR-007 — Canonical M0–M5 milestones
**Status:** Approved for M0 implementation by founder on 2026-10-13.

Earlier documents use different labels (some M4-A–M4-E); Blueprint §10–11 reconciles to: M0 foundation; M1 identity, tenancy and guardian safeguards; M2 learning loops; M3 constrained AI and Word Forge; M4 UX, privacy and operations; M5 staging/pilot. Preserve original story/test IDs in traceability; milestone renumbering must not imply acceptance tests were executed. Work stops at M0 until separate M1 approval.
