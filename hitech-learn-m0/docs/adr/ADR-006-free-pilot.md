# ADR-006 — Free pilot and excluded capabilities
**Status:** Founder direction recorded; M0 gate active.

About 100 users / 1–3 academies are pilot targets, not verified capacity. No payments, SMS, advanced CMS/blog, marketplace, native apps, voice/video tutor, advanced gamification, public minor leaderboards or large dashboards in P0. No automatic paid upgrade. M0 displays no checkout and hard-disables payments. Proposed short learner/academy loops are delivered only in M2, not by mock M0 UI.
